## 规则追溯、人工例子与验收

新增矩阵为 `evidence/exchange-rules-20261117/rules.csv`，逐条列明来源、产品、模式、
接口、适用时间、币种/单位、精度、限额、边界、核验范围、本地测试、所选政策及缺口。
测试编号指向既存用例；本轮没有重跑这些产品测试，更没有用网页证明它们通过。

- 同币合成例：总资产100、借款50、折扣0.8时，本系统风险权益为30；先净额再折扣
  会得到40。它验证本地保守政策，不能声称是真实Bybit账户的核对结果。
- 单位例：官方阶梯字段按币数量表达，本地档位按USD表达。即使有同一价格快照，
  仍需核实边际/整档算法与边界，再经独立案例验证，才能设计转换器；当前拒绝自动导入。
- 风险方向例：合成权益100、MM20时内部比率5。权益降至20时内部比率1并按本地
  政策触发；相同简化分母下的MM/权益为100%。这不省略交易所haircut/order loss分量。
- 模式例：官方模式名称存在不等于本系统已经支持。当前独立参考 PM 不可启用，
  服务的受控第一批仍是合成USD、Cross、现货与受限线性产品；USDT/USDC真实结算、
  Isolated、反向/交割/期权与组合抵消仍受各自未关闭门槛限制。
