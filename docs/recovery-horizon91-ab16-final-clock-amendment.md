# Final whole-clock and observed-native-status amendment

This new static successor preserves every file in proposal1e6e7f7 and the old
7ce/8f/81/b570 proposals and raw evidence. It is not an executed sample and does
not alter any past result. The new execution target, pending exact root and peer
GO, is `run_runtime_ab16_final.py` with
`runtime-ab16-final-preregistration.json`. All original financial/test sources,
fixed ABBA16 slots, scoped A/B runtime bindings, strict result/runtime/event
contracts, ordinary FAIL continue policy, 27/whole30 budgets and original
5/5/5/5/15 limits remain as previously registered.

The sample's elapsed clock is now read **once after every verification and source,
provider archive, executable and library posthash**. The same final_elapsed sets
the sample's whole30 flag, aggregate and reported whole_seconds. The old ordering
could check time before slow posthash work and report a larger elapsed duration
with a stale positive flag; that static proposal is preserved, not executed.

The caller also measures its actual sample invocation through return, including
the sample's END serialization/write. It saves a separate SLOT-OUTER-END record,
its original sample result and END hash, and applies that second whole30 gate
before deciding whether the next fixed slot may run. An outer overrun stops the
remaining slots and never overwrites or relabels the original sample END. The
outer evidence's own passive metadata write is outside the measured action;
there is no new business operation or cleanup hidden after that clock.

The bound `native-status-policy-amendment.json` explicitly references the prior
registration SHA e9d2b89050a206edba554a7a0c010293aa34a3093883ffeb05e2aee675005c8a.
A complete original native WriterFence.status start/error is the **observed
runtime subject**, not an unobserved recorder failure. Its real error and timings
must be retained; it can occur without stopping a technically complete diagnostic
sample. Such an error remains unknown financial authority, never healthy, grant
or renewal. Original production fail-closed behavior is unchanged. Every
supervisor kill still needs a later actual native expired ownership witness.
An original unittest ERROR, missing/invalid result or event, observer/logger/
sampler/source uncertainty, runtime mismatch, watchdog, forced cleanup, residual
process or whole overrun still stops the batch and preserves all remaining slots
as NOT_RUN. No runtime error is masked as financial health.

Root must approve the exact new controller and registration hashes in addition
to the already proposed helper/contracts/probe before execution. No new native
case was run while preparing this amendment. All passing samples would still be
NO_REPRO, with the old source91 failure unresolved and no production approval.
