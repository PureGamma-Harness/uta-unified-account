# main 基线与生产差距

## 可复核起点

起点为公开仓库 `main@30deff6`。该版本包含 8 个 Python 运行模块、39 项 unittest、手算与种子差分参考计算器、内存双分录账本、单进程预留、清算建议器、只读经典账户镜像及有界 reservation 模型。保留全部参考能力，新增持久交易主链路，不将参考计算器改作生产风控的同源验证。

首次在受限沙箱运行 39 项测试：38 项通过，HTTP 测试因禁止创建 socket 报权限错误；允许 loopback 后执行完整测试。该权限问题不是业务失败，也没有用 skip 掩盖。

main 没有性能脚本、硬件描述或原始压测输出，因此无法按相同口径复跑请求中提及的 10,809 次计算/判断、625 次持久化检查、359 笔模拟清算成交。它们记为**未经当前仓库证据验证的历史基线**。新工具保留原始到达/完成时间、唯一命令结果、吞吐分类及硬件环境，不拿纯计算或按标记价模拟成交替代交易验收。

## 原始问题及本次修正

| 原始差距 | 本次代码与证据 | 剩余启用门槛 |
| --- | --- | --- |
| 账本、预留和订单检查不相连；重启丢幂等记录 | `storage.py`、`service.py` 同事务账本/订单/仓位/事件，进程退出及并发测试 | 多节点复制、恢复水位与外部资金对账 |
| 请求者可自行提交余额和价格；无认证 | 独立认证网关、账户隔离、服务端行情与分权 | 公网签名/nonce、持久速率限制、IAM/MFA |
| 只有标记价和调用方时效保证 | 不可变版本行情，过期/未来/倒退拒绝 | 多源指数、异常行情与盘口保护控制面 |
| 没有真实双侧撮合或借贷闭环 | 第一里程碑补建本地撮合、gross 借贷与迁移工具 | 稳定币实际结算、外部托管与增量迁移 |
| 清算状态仅内存建议 | 持久计划、监督冻结、只减仓、重启恢复 | 成交深度/多腿最优化、保险基金和 ADL |

| 部分成交逐笔费用舍入可突破已预留上限 | 按订单累计名义计费后取差额，独立现金流测试 | 实际产品费率、返佣、资金费规则 |

| 缺少安装、备份与故障操作 | wheel、CI、私有数据文件、一致备份、离线恢复、SIGTERM drain | 目标主机演练、容量和多故障域容灾 |

## 批次与否决条件

当前提交只能进入合成数据的工程验收。第一批生产验收还需要：真实本地撮合全链路及四侧对账、现货/借贷冻结、正式产品目录和稳定币结算政策、历史数据校准、30 分钟开放环万笔容量、长稳与故障恢复、独立签核。任何一项缺失，第一批状态仍为 BLOCKED。

第二批（多结算币、交割、反向）和第三批（期权全量重估、合资格对冲和 PM 抵消）均默认禁止交易。存在参考估值或场景函数不等于对应产品获准启用。实现、验证、性能、运维和金融审批分别记录，不能用一个“测试通过”状态替代。
