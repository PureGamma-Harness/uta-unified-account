The original completed d421, 8b and 91 package work directories retained all 251 non-derived files byte for byte, including 44 original positive/negative archives and frozen-source tar files. Only their nine build-source, sdist-unpacked and venv directories were removed. Free space rose from 18,493,648,896 to 19,109,703,680 bytes at the recorded observation. This is not a reservation or launch approval.

The published allowlist records all original archive hashes and the hash of the complete private pre-cleanup file manifest. The original complete before/after records remain outside Git; no database contents or installed credentials are published. The cleanup driver is a record of this one action, not a command to rerun against missing targets. It refuses missing/symlink/non-owned targets and verifies all retained bytes after deletion.

Rebuild each source extraction from its retained frozen-source.tar; unpack the retained original positive sdist into a fresh directory; recreate a fresh venv and install the retained original wheel offline. Each package's original execution driver and artifact hashes remain in its public evidence. Do not rebuild or overwrite original artifacts or reinterpret historical test timings. No Git source, branch, authority, raw report, negative archive, running experiment, clock or signal was changed.
